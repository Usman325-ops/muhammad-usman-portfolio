# Muhammad Usman — Frontend Developer Portfolio

A responsive, animation-rich personal portfolio showcasing my frontend skills,
selected projects, résumé, and contact information.

## Live portfolio

[View the portfolio on GitHub Pages](https://usman325-ops.github.io/muhammad-usman-portfolio/)

## Highlights

- Responsive dark interface with animated auroras, particles, and hover effects
- Seven featured projects, including a music player, image gallery, Prism Games,
  and Neural Chat
- Downloadable résumé and contact form
- Built with Next.js, React, TypeScript, and CSS

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000/muhammad-usman-portfolio`.

## Production build

```bash
npm run build
```

The static output is generated in `out/` and deployed automatically through
GitHub Actions.

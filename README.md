## Highlights

- Responsive dark interface with animated auroras, particles, and hover effects
- Eight featured projects with corrected repository and live-demo links
- Three-song JavaScript Music Player with playlist, autoplay, progress, volume, and theme controls
- Downloadable résumé and contact form
- Built with Next.js, React, TypeScript, and CSS

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000/muhammad-usman-portfolio`.

## Production build

```bash
npm run build
```

The static output is generated in `out/` and deployed automatically through GitHub Actions.
